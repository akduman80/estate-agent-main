# Türkiye konum verisi

`turkey-neighborhoods.json`, Türkiye'nin 81 il, 973 ilçe ve mahalle
hiyerarşisini içerir. Veri, NVI kayıtlarıyla Mart 2026'da hizalanmış MIT lisanslı
[`onurusluca/turkey-geo-api`](https://github.com/onurusluca/turkey-geo-api)
projesinden 5 Eylül 2026 tarihinde alınmıştır. Kaynak veri yalnızca ad ve
hiyerarşi alanları tutularak uygulama için küçültülmüştür.
